# 山羊角宠物哨（goathorn）

把已驯服的动物绑到手上那根山羊角上，之后吹一下羊角，绑定的动物无论多远、所在区块有没有加载，都会传送到身边。一根羊角可以绑多只，一只动物只能属于一根羊角。

配套还有一处改动：装备装饰在第一人称潜行时统一下沉 0.6 格，解决挡视野的问题（在 cosmetic 插件里）。

---

## 1. 玩家怎么用

| 操作 | 效果 |
|---|---|
| 手持山羊角，`shift + 右键` 自己已驯服的动物 | 绑定到这根羊角 |
| 手持山羊角，右键空气（吹奏） | 把绑定的所有动物召回到身边 |
| `/goathorn list` | 查看当前羊角绑定了哪些动物 |
| `/goathorn reload`（OP） | 重载配置 |

绑定规则：

- 只有**已驯服**、且**主人是自己**的可驯服动物（狼、猫、鹦鹉等）能绑。
- 一只动物**只能绑一次**：已经绑到任何羊角上的动物，再绑会提示「这只宠物已经被绑定过了。」
- 一根羊角可以绑多只；单角上限由 `goathorn.max-animals-per-horn` 控制，0 = 不限。
- 绑定成功后羊角会出现**附魔光效**，描述（lore）里逐条列出绑定的动物。
  - 动物有自定义名字 → 显示「名字（类型）」；没名字 → 只显示类型。

召回规则：

- 吹奏后，绑定的动物逐一传送到玩家身边；**不限距离、不限区块是否加载**（未加载区块会先 `chunk.load()`）。
- 动物已经死亡或被清除 → 自动从羊角上摘掉，并刷新描述。
- 冷却由 `goathorn.cooldown-seconds` 控制（默认 5 秒），防连点把宠物来回拉。
- 吹奏有铃声 + 传送粒子（可关）。

---

## 2. 绑定存在哪

- **羊角侧**：数据写在山羊角自身的 `ItemStack` PDC 上，所以羊角放进箱子、丢在地上、给别人的都跟着走。
  - `bound-animals`：逗号分隔的动物 UUID 列表。
  - `bound-horn`：这根羊角的稳定 ID（第一次绑定时生成，之后复用；动物侧指向它）。
- **动物侧**：实体 PDC 上写 `bound-horn`（16 字节 UUID）+ `bound-owner`（主人 UUID），用来判断「这只动物已经被绑过」。

## 3. 一个必须记住的坑（26.3 物品 PDC）

26.3 里 `ItemStack.getPersistentDataContainer()` 返回的是 **`io.papermc.paper.persistence.PersistentDataContainerView`（只读视图）**，不能直接改。正确姿势：

```java
// 读：走 View / meta 都行
bindings.animalsOfItem(stack);

// 写：必须在 editMeta 里改，并且改完把 ItemStack 放回背包
boolean edited = stack.editMeta(meta -> {
    PersistentDataContainer c = meta.getPersistentDataContainer();
    ... // 写 bound-animals / bound-horn / 附魔 / lore
});
if (edited) {
    player.getInventory().setItemInMainHand(stack);
}
```

**`editMeta` 改的是 meta 的副本，不 `setItemInMainHand` 回写，改动会随这次调用一起丢掉。** 这是绑定曾经完全不生效的真根因。

## 4. 另一个坑：右键空气会被保护插件取消（本次真 bug）

现象：吹奏召回「间歇性失效」——有时成功，有时羊角吹了没反应。

根因：`onBlow` 监听 `PlayerInteractEvent` 原本是 `ignoreCancelled = true`，而领地/保护插件（如 GriefPrevention、WorldGuard）会把 `RIGHT_CLICK_AIR` `setCancelled(true)`，导致本监听器被整个跳过。所谓"间歇性"其实是事件偶尔没被取消的那几次。

修法：吹奏监听改为 **`ignoreCancelled = false`**：

```java
@EventHandler(priority = EventPriority.HIGH, ignoreCancelled = false)
public void onBlow(PlayerInteractEvent event) { ... }
```

吹奏羊角本来就不该被领地保护拦掉，真人右键和合成事件走同一条链，这个改动对两边都成立。

## 5. 第一人称视野修复（cosmetic）

`plugmc/plugins/cosmetic/src/main/java/com/xiyuan/plugmc/cosmetic/CosmeticDisplays.java` 的 `moveTo(...)` 里，在 pitchFollow 处理之后加：

```java
// 潜行时整体下沉 0.6 格：第一人称视角里装饰模型会挡住视野
if (player.isSneaking()) {
    dy -= 0.6;
}
```

所有部位（头/肩/背/腰/环绕）统一处理，避免逐槽位调参。

## 6. 配置

`plugmc/plugins/goathorn/src/main/resources/config.yml`：

```yaml
goathorn:
  # 吹奏冷却（秒）：防止连点右键把动物一波波拉过来
  cooldown-seconds: 5
  # 单只羊角最多绑多少只动物（0 = 不限）
  max-animals-per-horn: 0
  # 吹奏时播放铃声
  play-sound: true
  # 吹奏传送的粒子特效
  particles: true
```

> **配置只能整份 `Copy-Item` 拷贝**：之前的乱码配置（GBK 管道写坏）会让 Bukkit 静默丢掉后面的段，和敲钟 multipliers 那次是同一类事故。改配置后要重启服务器（`reload` 不重读 `plugin.getConfig()` 缓存）。

权限：`goathorn.use`（默认 true，使用）、`goathorn.admin`（OP，管理）。
