## 一、两条链路各管什么

| 链路 | 用途 | 入口 |
|---|---|---|
| **面板 API** `https://api.minekuai.cn/panel/client-api` | 读实例状态、读日志、**发控制台命令**、重启/停止 | `.local/minekuai.env` |
| **SFTP** `q1.minekuai.cn:10001` | 上传 jar / zip、删旧版本、备份线上数据 | `.local/sftp.env` |

关键事实（实测，别按直觉猜）：

- API **没有列目录端点**：`/files`、`/files/list`、`/resources` 全部返回 `{"code":404,"msg":"No endpoint ..."}`。列目录必须走 SFTP。
- API **可以按具体路径读文件**：`GET /files/contents?file=/server.properties` 返回真实内容——`server.properties` 和 `logs/latest.log` 都能这样读。
- API **可以发控制台命令**：`POST /command` + `{"command": "..."}`，回显落在 `latest.log` 里。**这是验证数据包/插件是否真生效的唯一手段**（`datapack list`、`plugins`、`version`、`eco selftest` 都是这么跑出来的）。
- API 的错误响应**也是 HTTP 200**，真实状态在 body 的 `code` 字段——所以不能只看状态码。

## 三、部署插件

```powershell
# 只检查不部署：读线上 latest.log，看现存插件是否都在 Enabling 列表里
python scripts/deploy_paper.py --check-only

# 真部署：构建 → 上传 jar → 备份线上数据 → 重启 → 校验 Enabling
python scripts/deploy_paper.py --plugin economy

# 复用已有 jar 不重新构建
python scripts/deploy_paper.py --plugin economy --skip-build

# 只上传不重启（下次重启生效）
python scripts/deploy_paper.py --plugin economy --upload-only

# 前 60 秒全服倒计时公告（无人在线自动跳过）
python scripts/deploy_paper.py --plugin economy --announce-seconds 60
```

脚本行为要点：

- 只删本次要部署的 `<id>-*.jar` 旧版本，不碰其它插件。
- 部署前把线上 `plugins/<id>/` 下载到 `.local/backup/remote-<时间>/`（`--no-remote-backup` 可跳过）。
- 重启后要求**先离开 running 或日志已变化**才认 `Done (`，避免被重启前那份日志骗过。
- 校验方式是日志里出现 `Enabling <插件名>` 或 `[<插件名>]`。

## 四、部署数据包

```powershell
# 构建 + 上传 zip 到 world/datapacks/ + 重启 + 校验
python scripts/deploy_datapack.py --pack plugmc-demo

# 只检查：读日志 + 发 /datapack list
python scripts/deploy_datapack.py --check-only

# 只上传不重启
python scripts/deploy_datapack.py --pack plugmc-demo --upload-only
```

与插件部署的区别：

- 数据包以 **zip 形式**放 `world/datapacks/`，服务端启动时自动发现（日志：`Found new data pack file/plugmc-demo.zip, loading it automatically`）。
- 上传前会清掉同名的旧 zip 和同名旧**文件夹**——两者不能共存，共存时哪个生效取决于加载顺序，容易踩坑。
- 校验用 `/datapack list`，应看到 `[file/plugmc-demo.zip (world)]`。

**已验证的坑**：`datapack list` 显示已启用 ≠ 函数真的跑了。唯一可信判据是日志里能看到数据包自己 `say` 的回执，或者手动 `function <命名空间>:load` 能跑通。

## 五、通过 API 发任意命令

没有现成脚本时，直接这样发：

```powershell
cd 'C:\Users\16923\Documents\原版服务器插件开发\plugmc'
$env:PYTHONIOENCODING='utf-8'
@'
import sys, time
sys.path.insert(0, "scripts")
import deploy_test as dt
env = dt.load_env(dt.ENV_FILES)
api = dt.Api(env.get("MINEKUAI_API_BASE", dt.API_DEFAULT),
             dt.need(env, "MINEKUAI_API_KEY"), dt.need(env, "MINEKUAI_SERVER_ID"))
before = api.log()
api.request("POST", "/command", json={"command": "datapack list"})
time.sleep(2.5)
fresh = api.log()[len(before):]
print("\n".join(l for l in fresh.splitlines() if "spark" not in l))
'@ | Set-Content -Path .local\_cmd.py -Encoding utf8
python .local\_cmd.py
```

`command` 字段**不能为空**（会返回 `422 参数错误 命令不能为空`），所以 `version` 这种命令也要正常写全。
