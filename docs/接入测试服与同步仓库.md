# 接入测试服与同步仓库：需要你做的事

这份文档只列**必须由你本人完成**的动作（登录、拿密钥、授权）。

---

## 一、拿到麦块联机的 API 密钥与实例 ID

1. 浏览器登录 <https://minekuai.com/>
2. 进入你的**插件测试服**实例页
3. 在面板里找 **API / 开发者 / 密钥** 一类的入口，生成一个 API 密钥
   - 提示：`client-api` 这个接口按 401 返回 `{"error":"缺少或无效的 API 密钥"}`，说明密钥走 `Authorization: Bearer <key>` 头
   - 密钥可能有**来源 IP 白名单**，如果拿不到权限请顺手确认你的公网 IP 已加白
4. 记下**实例 ID**（实例页 URL 里那串，或面板概览里的 Server ID）

## 二、拿到 SFTP 凭据

面板里找 **文件 / SFTP / 连接信息**，会有：

- 主机（形如 `xxx.minekuai.cn` 或一个 IP）
- 端口（一般 22 或面板指定的高位端口）
- 用户名
- 密码

## 五、你做完之后我会执行的命令

```powershell
cd 'C:\Users\16923\Documents\原版服务器插件开发\plugmc'
$env:PYTHONIOENCODING='utf-8'

# 1. 只读自检：确认 API 能读日志、SFTP 能列 plugins/
python scripts/check_credentials.py

# 2. 只检查不部署：读线上 latest.log 看现存插件是否都在
python scripts/deploy_paper.py --check-only

# 3. 真部署（构建 → 上传 jar → 重启 → 校验 Enabling）
python scripts/deploy_paper.py --plugin <插件id>

# 4. 只看某个插件
python scripts/deploy_paper.py --plugin anti-xray --skip-build
```

`deploy_paper.py` 的上游版本已经带 `--announce-seconds N`（重启前全服倒计时公告，无人在线自动跳过）和部署前的线上数据备份（`.local/backup/remote-<时间>/`）。
